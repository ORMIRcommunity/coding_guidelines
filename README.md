# Coding guidelines

This repository contains the material in the [Coding Guidelines](https://www.ormir.org/coding_guidelines) of the [ORMIR Community](https://www.ormir.org/). 

## Contributing
Thanks for your interest in contributing! The contributing guidelines are... in the [Coding Guidelines](https://www.ormir.org/coding_guidelines/docs-contributing/)!

Add your figures to the folder `figures`. There is also a file to draft the figures, called `ormir_code_guidelines_figures.pptx`, if that is convenient for you!

For the schemes, we have fun with [Mermaid](https://mermaid.ai/open-source/syntax/flowchart.html). The yellow color we use is: `fill:#ffd42aff,stroke:#d6b656,stroke-width:2px`
